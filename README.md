### 💻 What I've Built (My Projects)

I spend my time engineering frameworks and tools that make developers' lives easier, as well as researching AI and algorithmic platforms:
*   **[The Ferrox Ecosystem](https://ferrox-rust.dev) (Lead Architect & Creator):** An enterprise-grade, blazing-fast Cloud-Native framework suite available across multiple languages:
    *   **[ferrox (Rust)](https://github.com/AI-Autistic-Intelligence/cargo-ferrox):** Brings NestJS ergonomics into Rust (Axum, Tokio, SeaORM) for ultra-high performance microservices.
    *   **[ferrox-node (Node.js/TypeScript)](https://github.com/AI-Autistic-Intelligence/ferrox-node):** A comprehensive suite of cloud-native modules, CQRS, and infrastructure tools.
    *   **[ferrox-py (Python)](https://github.com/AI-Autistic-Intelligence/ferrox-py):** Advanced Python tooling, commerce, and auth modules.
    *   **[ferrox-php (PHP)](https://github.com/AI-Autistic-Intelligence/ferrox-php):** PHP integrations and modern backend tools.
    *   **[ferrox-java](https://github.com/AI-Autistic-Intelligence/ferrox-java):** Next-gen Java 21 module utilizing **Project Panama** (Zero-GC Off-Heap caching), **Virtual Threads (Loom)**, and **PASETO Zero-Trust** security.
*   **Microservices Standardization:** Co-authored **[nestjs-yalc](https://github.com/Drassil/nestjs-yalc)** & **[node-yalc](https://github.com/AI-Autistic-Intelligence/node-yalc)**, enterprise toolkits enabling automated logging and unified API response schemas across multi-project backend suites.
*   **AI Infrastructure & Algorithmic Trading:** Authored open-source MLOps and AI projects (**[AI_SurviveStrategy](https://github.com/AI-Autistic-Intelligence/AI_SurviveStrategy)**, **[Advanced_Market_Forecaster](https://github.com/AI-Autistic-Intelligence/Advanced_Market_Forecaster)**) and **[ferrox-bid](https://github.com/AI-Autistic-Intelligence/ferrox-bid)** (microsecond-latency HFT engine in Java 21).
*   **Low-Latency Bridges & Launchers:** Engineered market data streaming bridges (Java/Spring Boot, MQL5/ZeroMQ, Python) and desktop platform launchers integrating C++, Electron, and React.
